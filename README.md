# Rails Application Templates

Opinionated Rails 8 application template with Devise, Pundit, Tailwind CSS, and FactoryBot.

## Usage

```bash
rails new myapp -m /path/to/template.rb

# With PostgreSQL (adds Docker Compose + database.yml config)
rails new myapp -d postgresql -m /path/to/template.rb
```

See [template.rb](template.rb) for details.
